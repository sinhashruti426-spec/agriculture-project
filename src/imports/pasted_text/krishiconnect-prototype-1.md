Create a **high-fidelity, clickable UI/UX prototype only** for an SIH solution called **“KrishiConnect”**, an integrated farmer-support platform connecting the complete agricultural value chain:

**👨‍🌾 Farmer → 🌱 Production → ⚙️ Processing → 💎 Value Addition → ♻️ Waste-to-Value → 🤝 Market → 🚚 Transport**

with **👨‍🏫 Expert Guidance** supporting every stage.

### CORE PURPOSE

Design a simple, modern, highly intuitive platform for farmers to get expert guidance, discover relevant stakeholders, connect with processors/buyers/waste-utilization partners/transporters, and track requests across the agricultural value chain.

### CORE PROTOTYPE SCREENS

1. **Splash / Welcome**

   * Clean agricultural identity
   * Simple tagline: “From Farm to Value, One Connected Journey”
   * Farmer-friendly visual

2. **Farmer Home Dashboard**

   * Large visual cards for:

     * 👨‍🏫 Ask an Expert
     * 🌱 Production Support
     * ⚙️ Processing
     * 💎 Value Addition
     * ♻️ Waste-to-Value
     * 🤝 Find Buyers / Market
     * 🚚 Find Transport
   * Location selector
   * Language selector
   * Voice interaction button
   * Notifications
   * Clear, low-literacy-friendly navigation

3. **Expert Guidance**

   * Select crop/problem
   * Upload photo/video
   * Voice input
   * Regional-language interaction
   * Expert categories such as experienced farmers, agricultural specialists and relevant professionals
   * Verified expert profiles
   * Ratings/reviews
   * Request guidance CTA

4. **Production Support**

   * Crop selection
   * Problem identification through photo/video
   * Production guidance
   * Relevant supplier/service discovery
   * Location-based results

5. **Processing & Value Addition**

   * Select crop/product
   * Show possible processing pathways
   * Show potential value-added products
   * Connect farmer with relevant processors/service providers
   * Display simple reference value/price guidance

6. **Waste-to-Value**

   * Enter or select waste type
   * Quantity
   * Location
   * Show possible uses/value pathways
   * Connect with relevant waste-utilization stakeholders
   * Reference value guidance

7. **Market / Buyer Discovery**

   * Buyer/company cards
   * Product/category
   * Location
   * Indicative/reference price
   * Verified badge
   * Reviews
   * “Send Request” CTA

8. **Transport**

   * Pickup location
   * Destination
   * Transport requirement
   * Suitable transporter cards
   * Basic request flow

9. **Request / Transaction Tracking**

   * Visual progress tracker:
     **Request → Accepted → Processing → Ready → Transport → Completed**
   * Status cards
   * Dates/status indicators
   * Simple farmer-friendly language

10. **Profile & Verification**

* Farmer profile
* Verified stakeholder badges
* Reviews and ratings
* Previous requests
* Saved information

### IMPORTANT SUPPORTING FEATURES

Represent these visually in the prototype:

* 📷 Photo/video upload
* 🎤 Voice interaction
* 🌐 Regional languages
* 📍 Location-based discovery
* 💰 Reference price/value guidance
* 🔎 Rule-based stakeholder matching
* ✅ Verified profiles
* ⭐ Reviews & ratings
* 📊 Request/transaction tracking
* 📶 Low-network-friendly UX
* 💾 Draft saving/sync concept for weak connectivity
* 👨‍🌾 Farmer-friendly, low-literacy UX

### UI/UX DIRECTION

Make the design **professional, polished, modern and SIH-finalist quality**.

Prioritize:

* Extremely simple navigation
* Large touch-friendly buttons
* Clear icons with text
* Minimal typing
* Strong visual hierarchy
* Readable typography
* High contrast
* Clean agricultural visual language
* Consistent cards and components
* Clear CTAs
* Trust indicators and verified badges
* Location-aware interface
* Regional-language-ready layouts
* Voice-first interaction where useful
* Accessible design for users with low digital literacy

Use a **fresh, trustworthy agricultural visual identity** with natural tones, clean whites, subtle gradients, modern illustrations and professional dashboards. Avoid excessive decoration, tiny text, complicated menus, generic corporate templates, or unrealistic futuristic AI visuals.

### PROTOTYPE INTERACTION

Create a **clickable demonstration flow**, not a functional application.

The main demo journey should be:

**Home → Ask Expert → Upload Crop Photo → Select Problem → View Expert → Request Guidance → Production → Processing → Value Addition → Waste-to-Value → Find Buyer → Transport → Track Request**

Use realistic sample farmer/stakeholder data only to demonstrate the interface.

### STRICT SCOPE

**THIS IS ONLY A HIGH-FIDELITY UI/UX PROTOTYPE.**

Do NOT create:

* Backend
* Database
* APIs
* Authentication systems
* Server logic
* Real payments
* Real-time tracking
* Actual AI/ML implementation
* Functional marketplace
* Functional voice recognition
* Production-ready code
* Deployment configuration

All functionality should be **simulated visually for prototype demonstration** using realistic mock data and clickable interactions.

The final result must look like a **real, polished SIH prototype demonstrating the complete solution journey**, with emphasis on **clarity, usability, innovation, stakeholder connectivity and farmer-centric design**.
